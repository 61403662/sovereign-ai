# Contributing

Thanks for helping extend sovereign-ai.

## Boundaries

- Do **not** commit private documents, databases, vector indexes, API keys, or `config/models.yaml` with internal URLs.
- Prefer `data/samples/` for tiny anonymized fixtures.

## Workflow

1. Fork and create a branch from `main`.
2. Keep changes focused; describe how to test manually in the PR.
3. Ensure CI passes (lint/tests use mocks—no model downloads in CI).

## Commits

Clear one-line subject; body optional. English or Chinese is fine.
