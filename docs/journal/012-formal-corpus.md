# 主权 AI-12：复合答——一句里既要文档又要价钱

> Phase 2 全貌 **`docs/PHASE2-ROADMAP.md`**。本篇 **支柱 I**：**`route: compound`**，RAG + SQL **各跑一遍**再合并；**不是** AI-10 的单路混合（价赢只走 SQL）。

## 开篇

**AI-07～11** 始终是 **一句一问、一条路**：要么翻 `data\raw`，要么查 `fan_bom.db`。**AI-10** 处理的是 **混合句选路**（检验 + 材料费 → 仍只走 SQL）；**AI-11** 在浏览器里看见 **intent / data**。

现场还会有一种问法：

> **扇叶划痕能否让步？同时 XF-120 材料费多少钱？**

这时你 **既要 SOP 段落，又要 26.7**——单路不够。**AI-12** 做 **复合答（compound）**：显式带 **「同时、并且、还要」** 等词，且 **同时** 出现文档词与询价词时，**RAG 与 SQL 都跑**，答案分两段 **【文档与规程】** / **【BOM 与价钱】**。

**诚实边界（POC）**：靠 **连接词 + 关键词** 触发，不是通用意图拆分；**eval-all 13/13 不变**，复合另有 **`eval/compound_qa.example.jsonl`**。

## 一、和 AI-10 别混

【图1】

| 情况 | route | 说明 |
|------|-------|------|
| XF-120检验时材料费多少钱？ | **sql** | 价赢，**一路** |
| 让步？**同时**材料费多少钱？ | **compound** | **两路都答** |

没有「同时」类连接词 → 行为与 10 相同，**不**自动复合。

## 二、触发条件（大白话）

【图2】

1. BOM 库已就绪；  
2. 问句里有 **同时 / 并且 / 还要 / 顺便 / 另外** 之一；  
3. 既有 **检验、让步、工艺…** 等文档词，又有 **材料费、多少钱、BOM…** 等询价词。

实现：`sovereign_ai/ask/compound.py`；入口在 `ask_question()` **优先于** 单路 SQL。

## 五、边界

- 未覆盖「无连接词的双重要求」；口语变体需补词。  
- RAG 失败 → 回落仅 RAG；SQL 失败 → 仅 RAG 段（不硬编价）。  
- 不做多轮、不做云端选路。
